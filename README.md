## Padrão das entregas

Ao trabalhar em notebooks ou arquivos Quarto:

1. Organizar o código em uma sequência lógica de células executáveis.
2. Incluir a **interpretação textual logo após cada resultado relevante**, como tabelas, medidas estatísticas e gráficos.
3. Explicar o que os valores representam, quais conclusões são justificadas e como respondem à questão.
4. Conferir a execução do notebook e registrar alterações em commits progressivos.

O guia [Como interpretar os resultados](docs/GUIA_DE_INTERPRETACOES.md) descreve a estrutura de escrita, sem respostas das atividades.
