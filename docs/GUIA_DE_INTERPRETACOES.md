# Guia de interpretação dos resultados

O professor pede **interpretação por bloco**: após cada saída relevante de código, deve haver texto explicativo.

## Estrutura sugerida para a célula Markdown

**Resultado observado:** descreva, com as unidades corretas, os números ou padrões mostrados pela saída.

**Interpretação:** explique o significado do resultado para o conjunto de dados analisado.

**Conclusão para a questão:** diga o que é possível concluir e, quando pertinente, quais são as limitações da análise.

## Atenção

- Não repetir somente o comando executado ou o nome da função.
- Não afirmar causalidade a partir de uma simples correlação.
- Não tirar conclusões que os dados não sustentem.
- Explicar gráficos e tabelas com clareza.
- Usar os resultados reais depois de executar o próprio código.

Este documento é apenas um guia de organização; **não contém soluções de laboratório**.
